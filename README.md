# Finding the Complexity of Algorithm

A dedicated repository for analyzing, documenting, and calculating the time and space complexity of various computational algorithms. This project serves as a comprehensive reference guide for understanding algorithmic efficiency, Big O notation, and performance optimization.

## 📌 Project Overview
Understanding algorithm complexity is essential for writing scalable, efficient code. This repository breaks down complex data structures and algorithms, evaluates their performance under different scenarios (Best, Average, and Worst cases), and documents practical analysis methods.

*   **Current Focus:** Core analysis frameworks, theoretical breakdowns, and performance documentation (e.g., `Finding the complexity of algorithm.docx`).
*   **Target Algorithms:** Sorting, searching, tree traversals, graph algorithms, and dynamic programming patterns.

## 📊 Quick Reference: Big O Complexity Cheat Sheet

| Data Structure / Algorithm | Time Complexity (Best) | Time Complexity (Worst) | Space Complexity (Worst) |
| :--- | :--- | :--- | :--- |
| **Binary Search** | $O(1)$ | $O(\log n)$ | $O(1)$ |
| **Quick Sort** | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ |
| **Merge Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ |
| **Hash Table Lookup** | $O(1)$ | $O(n)$ | $O(n)$ |

## 🛠️ Getting Started

### Prerequisites
To read the comprehensive documentation included in this repository, you will need:
*   A markdown viewer (built into GitHub or VS Code)
*   Microsoft Word or a compatible office suite (to view `.docx` analysis files)

### Installation & Local Setup
To download and explore this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Finding-the-complexity-of-algorithm
   ```

3. **View the files:**
   Open the repository in your favorite code editor (like VS Code) or open the documentation files directly.
